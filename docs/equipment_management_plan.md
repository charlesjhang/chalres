# 器材管理工具需求規劃

## 1. 系統概念
- 目的：提供個人或團隊管理各類器材的集中平台，掌握器材狀態、位置與保固資訊。
- 結構：以「大分類」區分不同場景（例：個人、攝影工作室），每個大分類底下可以自行調整「小分類」以整理器材種類。
- 擴充性：所有分類與欄位設定保留使用者自訂空間，預設提供一組範本供快速啟用。

## 2. 分類規劃
### 2.1 大分類範本（可增刪）
1. **個人器材管理**：適合個人創作者、學生。
2. **攝影工作室器材管理**：適合中小型影像團隊。
3. **錄音/直播工作區**：著重音頻與串流設備。
4. **公司內部共享資源**：適合部門共用器材。

> 使用者可依據實際需求自訂更多大分類，例如「活動租借器材」或「教育訓練器材」。

### 2.2 小分類預設清單（可依大分類複製調整）
| 類型 | 小分類 | 說明 |
| --- | --- | --- |
| 電子類 | 電腦 / 筆電 | 主力作業機、剪輯機等 |
|  | 相機機身 | DSLR、無反、傻瓜相機 |
|  | 鏡頭 | 定焦、變焦、特效鏡 |
|  | 攝影機 / 運動相機 | 影片拍攝設備 |
|  | 手機 / 平板 | 行動拍攝或工作站 |
|  | 麥克風 | 指向型、領夾、電容等 |
|  | 錄音介面 / 混音器 | 收音與音訊處理 |
|  | 燈具 / 燈控器材 | LED燈、閃燈、控制器 |
|  | 無人機 / 穩定器 | 空拍機、手持穩定器 |
| 其他設備 | 腳架 / 獨腳架 | 攝影支撐器材 |
|  | 滑軌 / 升降台 | 運鏡設備 |
|  | 背景架 / 背景紙 | 佈景器材 |
|  | 反光板 / 柔光箱 | 打光輔具 |
|  | 收納箱 / 保護套 | 儲存與保護器材 |

|  | 工具與維修用品 | 螺絲工具、清潔套件 |

> 可讓使用者自行新增或刪除小分類，並支援排序、合併、批次套用至其他大分類。

## 3. 物品資料欄位
| 欄位 | 類型 / 格式 | 說明 |
| --- | --- | --- |
| 名稱 | 文字（必填） | 器材名稱或型號 |
| 圖片 | 多張影像上傳 | 支援拖拉上傳、預覽、標註封面 |
| 購買日 | 日期 | 用於計算保固與折舊 |
| 是否有保固 | 布林切換 | 決定是否顯示保固相關欄位 |
| 保固到期日 | 日期 | 自動由購買日 + 年限或手動輸入 |
| 物品位置 | 下拉 / 標籤 | 例如「器材室A架」、「外出包」 |
| 購買金額 | 數字 + 貨幣 | 支援多幣別換算 |
| 購買管道 | 文字 + URL | 可填寫店家名稱與連結 |
| 使用說明書 | 檔案上傳 / 連結 | 可儲存 PDF 或線上說明網址 |
| 備註 | 長文字 | 補充保養、狀態、租借紀錄等 |
| 自訂欄位 | 使用者新增 | 例如序號、保險資訊、租借費率 |

## 4. 功能流程建議
1. **分類管理**
   - 建立 / 編輯 / 刪除大分類。
   - 大分類中維護小分類清單，支援拖曳排序與批次管理。
   - 提供預設範本一鍵匯入。
2. **物品管理**
   - 在選定大分類與小分類下新增物品。
   - 上傳多張圖片、設定封面、支援壓縮。
   - 自動根據「購買日」與「保固年限」計算保固到期提醒。
   - 記錄物品位置並顯示可用狀態（在庫、外借、維修中）。
   - 支援匯出 Excel/CSV、批次匯入。
3. **搜尋與篩選**
   - 依小分類、位置、保固狀態、價格區間等條件過濾。
   - 快速搜尋欄位支援關鍵字匹配名稱、備註。
4. **附件與文件管理**
   - 圖片與說明書集中存放，支援下載與分享連結。
   - 可在物品頁查看保養紀錄、維修歷史（可選功能）。
5. **權限與通知（進階）**
   - 多使用者登入、權限控管。
   - 保固到期、借出期限提醒（Email/推播）。

## 5. 後續擴充建議
- 與日曆整合，追蹤器材預約與借用。
- 支援手機掃碼（QR Code/NFC）快速取得物品資訊。
- 整合財務報表：折舊計算、年度購置分析。
- API / Webhook 介面，方便與其他系統串接。
- 建立維修與保養紀錄模組，保留歷史追蹤。

此規劃提供初始開發方向，可依實際需求調整細節並逐步實作。
